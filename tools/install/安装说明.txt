============================================
 童年游戏厅 v2.0 整合版 · 安装说明
============================================

本安装包是「童年游戏厅 2.0」整合版：
  · 976 个游戏版本（940 款游戏 + 36 款官方新增改版）
  · 全部为中文游戏名，英文原名保留在「别名」里照样能搜到
  · FBNeo 街机内核（含金属弹头改版专用内核）
  · CRT 着色器、RGNE 面框、竖屏打飞机自动旋转
  · RetroArch 风格存储：游戏和封面都放在 sdcard，可自行增删

---- 文件夹里有什么 ----
  童年游戏厅-v2.0-整合版-通用.apk   主程序（157MB，含 32+64 位内核，任何设备都能装）
  童年游戏厅-v2.0-整合版-arm32.apk   仅 32 位内核版（88MB，老设备用）
  童年游戏厅-v2.0-整合版-arm64.apk   仅 64 位内核版（94MB）
  游戏数据包-v2.0.zip               游戏数据（3.95GB，解压后到 sdcard）
  童年游戏厅游戏库编辑器.exe          游戏库编辑器（Windows 双击即用，无需装 Python）
  platform-tools\                    自带的 adb 工具（方式二用）
  安装.py                            一键安装脚本（方式二用）
  安装说明.txt                       本说明

---- 数据放在哪 ----
  /sdcard/ChildhoodArcade/
      nes/        games.json（已格式化）+ covers/ + roms/
      arcade/     同上（含 neogeo.zip / pgm.zip 等 BIOS）
      gba/        同上
      md/         同上
      sfc/        同上

  游戏厅设置 → 游戏资源 → 「游戏目录」可切换到别的目录。

============================================
 方式一（推荐）：平板直接装，不用电脑
============================================
 1. 把 APK 和「游戏数据包-v2.0.zip」拷到平板
 2. 装 APK（首次启动弹「读取存储」权限 → 点「允许」）
 3. 用文件管理器把 zip 解压到 /sdcard/ ，得到 /sdcard/ChildhoodArcade/
 4. 打开游戏厅

============================================
 方式二：电脑一键安装
============================================
 1. 平板开「开发者选项 → USB 调试」，数据线连电脑
 2. 电脑装好 Python 3，双击运行「安装.py」
    （脚本自动解锁屏幕、自动确认 OPPO 安装弹窗、自动同意读取存储权限）

============================================
 游戏库编辑器（Windows 图形界面）
============================================
 双击「童年游戏厅游戏库编辑器.exe」即可使用，**无需安装 Python 或任何环境**。

  功能：
   · 打开游戏目录    选 /sdcard/ChildhoodArcade/ 那层目录
   · 预览            选中游戏即显示封面与完整资料
   · 新增游戏        选 ROM 自动归类平台、自动算 SHA256、自动生成条目；
                     新增时可选 BIOS（默认按游戏名智能判断，如拳皇→neogeo、
                     三国战纪→pgm），下拉只列该平台目录里真正的 BIOS
   · 删除选中        从清单移除，可选连带删除 ROM / 封面
   · 编辑            标题、别名、类型、人数、版本、封面、BIOS 等
   · 批量编辑        多选批量赋值 + 正则查找替换（带预览）
   · 匹配规则        清单与磁盘文件对应：精确/忽略大小写/去扩展名/模糊/正则/按哈希
   · BIOS 管理       查看各平台已有 BIOS、校验值、被引用数，可一键批量改用

  改完记得点「保存全部」（按平台写回格式化的 games.json）。

  提示：可给 exe 建个快捷方式，在「目标」后面加上游戏目录路径，
        双击就直接打开那个目录。

---- 常见问题 ----
 Q: 安装时卡住不动？
 A: 手机锁屏时 OPPO 会卡住安装，先解锁屏幕再运行脚本。

 Q: 游戏列表是空的 / 封面不显示？
 A: 没给「读取存储」权限，或数据没解压到 /sdcard/ChildhoodArcade/。

 Q: 某些街机游戏报「未能完成初始化」？
 A: 该平台目录缺少 BIOS（neogeo.zip / pgm.zip）。确认 arcade/roms/ 里有这些文件。

 Q: 检查完整性报缺失？
 A: 校验的是 sdcard 上的实际文件；确认解压完整、目录结构正确。

  Q: 想自己加游戏？
  A: 用「游戏库编辑器」新增，或手动放 ROM 进对应 roms/ 后在编辑器里
     「匹配规则 → 补全缺失条目」。

  Q: 搜不到某个游戏？
  A: 现在全部用中文名显示，但英文原名、拼音、首字母缩写都保留在「别名」里，
     例如搜 "concentration"、"cs"（彩色方块）、"kof97" 都能搜到。

---- 关于两个删掉的游戏 ----
  · 合金弹头3 改版「mslug3nd」：中文盗版 ROM，FBNeo / MAME 都没有对应驱动，
    任何内核都跑不了，已从库中移除。
  · 热血硬派2「pwrinst2」：你的 ROM 是 MAME 格式，和 FBNeo 的 CRC 对不上。
    若换成 FBNeo 版 ROM（在 ARCADE-FBN 目录里），可在编辑器里改回来。
