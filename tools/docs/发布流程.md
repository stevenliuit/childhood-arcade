# 发布流程

把产物挂到 GitHub Release 上。

---

## 1. 先把代码推上去

```powershell
git add -A
git commit -m "..."
git push origin main
```

`.gitignore` 已经排除了 `*.apk` / `*.zip` / `*.nes` / `*.gba` / `*.sfc` / `*.exe`，
所以 ROM 和二进制不会被提交进仓库——它们只作为 Release 附件分发。

> keystore 和密码**永远不要**进仓库。打包时用环境变量 `ARCADE_KS_PASS` 传。

---

## 2. 整理发布目录

```powershell
python tools/build/build_all.py --split 1900
```

产物在 `_out/release/`：

```
childhood-arcade-2.0.0-integrated-universal.apk    157 MB
childhood-arcade-2.0.0-integrated-arm32.apk         88 MB
childhood-arcade-2.0.0-integrated-arm64.apk         94 MB
childhood-arcade-editor-2.0.0.exe                    20 MB
childhood-arcade-editor-src-2.0.0.zip               小     ← 编辑器源码 + 打包脚本
游戏数据包-v2.0.zip.part1 / .part2 / .part3          各 ~1.3 GB
合并数据包.py                                          小     ← 合并分卷用
安装.py / 安装说明.txt                                小
SHA256SUMS.txt                                       小     ← 所有附件的校验值
```

---

## 3. 建 Release

### 用 gh CLI（推荐）

```powershell
gh release create v2.0.0-integrated `
  --title "童年游戏厅 v2.0 整合版" `
  --notes-file RELEASE_NOTES.md `
  _out/release/*
```

### 用 API（没有 gh 时）

```powershell
$tok = (Get-Content .\ghtok.txt -Raw).Trim()
$body = @{ tag_name = "v2.0.0-integrated"
           name     = "童年游戏厅 v2.0 整合版"
           body     = (Get-Content RELEASE_NOTES.md -Raw)
           draft    = $false
           prerelease = $false } | ConvertTo-Json

$rel = Invoke-RestMethod -Method Post `
  -Uri "https://api.github.com/repos/<owner>/<repo>/releases" `
  -Headers @{ Authorization = "Bearer $tok"
              Accept = "application/vnd.github+json"
              "User-Agent" = "release-bot" } `
  -Body ([Text.Encoding]::UTF8.GetBytes($body)) `
  -ContentType "application/json; charset=utf-8"

$upload = "https://uploads.github.com/repos/<owner>/<repo>/releases/$($rel.id)/assets"
foreach ($f in Get-ChildItem _out\release) {
  Invoke-RestMethod -Method Post -Uri "$upload?name=$([uri]::EscapeDataString($f.Name))" `
    -Headers @{ Authorization = "Bearer $tok"; "User-Agent" = "release-bot" } `
    -ContentType "application/octet-stream" `
    -InFile $f.FullName
}
```

上传大文件要**放宽超时**，4 GB 的包别用默认超时：

```powershell
curl.exe --max-time 7200 -T 资产文件 `
  -H "Authorization: Bearer $tok" `
  -H "Content-Type: application/octet-stream" `
  "https://uploads.github.com/repos/<owner>/<repo>/releases/<id>/assets?name=<文件名>"
```

---

## 4. 体积与限制

| 限制 | 数值 | 应对 |
|---|---|---|
| 单个附件 | **2 GiB** | 数据包分卷（`--split 1900`） |
| 单次 Release 附件总量 | 1000 个 | 分开够用 |
| Release 数量 | 无硬限制 | — |

分卷命名用 `xxx.zip.part1 / .part2 / .part3`，
用户下齐后跑 `合并数据包.py` 合并，再解压到 `/sdcard/`。

---

## 5. 发布后

- README 里的下载链接改成新 tag 的地址
- 把 `SHA256SUMS.txt` 一起挂上去，用户可以核对
- 数据包里的 `games.json` 是**格式化**过的 JSON，用户可以直接用编辑器改
